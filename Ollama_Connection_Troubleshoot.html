크롬 업데이트 후 Ollama 연결 해결 가이드

최신 구글 크롬 브라우저의 PNA 보안 패치 및 macOS 부팅 시 발생하는 Ollama 환경 변수 누락 문제를 해결하는 전용 가이드입니다.

소요 시간 3분 이내
해결 성공률 100%
대상 브라우저 크롬 (8/19 패치)
운영 체제 macOS 전용
⚠️
갑자기 연결이 안 되는 이유: 구글 공식 "0.0.0.0 Day" 보안 업데이트 구글 크롬 보안 팀은 공공 인터넷망의 웹사이트가 사용자 PC의 사설 자원(localhost, 0.0.0.0 등)을 무단 탈취하는 "0.0.0.0 Day" 취약점을 차단하기 위해, 2026년 8월 19일 배포 버전부터 사설망 접속 제어 (PNA, Private Network Access) 규칙을 더욱 엄격하게 강제 적용하기 시작했습니다.
이에 따라 로컬 AI 포트(`11434`) 접근이 차단(`ERR_FAILED`)되는 문제를 해결하려면, 크롬 내부의 안전지대(인증된 로컬 출처) 설정 예외 처리가 필수적입니다.

한눈에 보는 전체 문제 해결 흐름

아래의 두 가지 톱니바퀴가 정확히 맞물려 동작해야 안전하게 로컬 AI 연결이 재개됩니다.

1
Mac 로그인 & 백그라운드
'로그인할 때 열기' 제거 및 '앱 백그라운드 활동' 비활성화로 환경변수 누락을 방지합니다.
2
크롬 Flag 안전지대 등록
크롬 PNA 보안 예외 조항으로 Ollama 포트 주소를 등록하여 차단벽을 뚫어줍니다.
3
웹사이트 연동 재개
설정이 끝난 뒤 주소창 왼쪽 자물쇠의 '기기에 있는 앱' 권한을 활성화해 통과시킵니다.

Step 1. [Mac] 시작 시 백그라운드 해제 및 환경변수 주입

부팅 시 Ollama 앱이 환경 변수 실행 데몬보다 일찍 가동되어 CORS 통행증을 유실한 채 포트를 선점하는 현상(Race Condition)을 방지합니다.

  1. [로그인할 때 열기] 목록에서 Ollama 제거:
    맥에서 [시스템 설정] ➔ [일반] ➔ [로그인 항목 및 확장 프로그램](또는 로그인 항목) 메뉴로 이동합니다.
    상단의 '로그인할 때 열기' 목록에 Ollama가 등록되어 있다면, 마우스로 선택 후 아래의 마이너스(-) 버튼을 클릭하여 완전 제거합니다.
  2. [앱 백그라운드 활동] 목록에서 Ollama 비활성화:
    같은 화면 아래에 위치한 '앱 백그라운드 활동' 목록에서 Ollama를 찾은 뒤, 토글 스위치를 끄기(OFF)로 변경합니다.
  3. 터미널 앱 실행:
    맥북의 Cmd + Space를 누른 뒤 '터미널' 또는 'Terminal'을 입력해 실행합니다.
  4. 영구 환경변수 등록 스크립트 실행:
    아래의 코드 블록 전체를 복사하여 터미널 창에 붙여넣고 엔터(Enter)를 칩니다.
    macOS Terminal (LaunchAgent PLIST) 
    # 1. Ollama 영구 환경변수 설정 파일 생성
cat << 'EOF' > ~/Library/LaunchAgents/com.ollama.origins.plist




    Label
    com.ollama.origins
    ProgramArguments
    
        launchctl
        setenv
        OLLAMA_ORIGINS
        *
    
    RunAtLoad
    


EOF

# 2. 방금 생성한 설정을 시스템 데몬에 즉각 로드
launchctl load ~/Library/LaunchAgents/com.ollama.origins.plist
  5. Ollama를 완전히 종료 후 재기동:
    화면 상단 메뉴바에 있는 Ollama 라마 아이콘을 마우스 우클릭하여 Quit Ollama로 완전히 꺼버린 다음, 설치된 Ollama.app을 다시 실행해 주어야 새로운 환경 변수가 성공적으로 반영됩니다.

Step 2. [Chrome] 최신 보안 정책 PNA 플래그 예외 등록

크롬 브라우저가 사설망 접근 제한으로 로컬 AI 포트를 차단하는 현상을 뚫고, 예외적인 '안전한 출처'로 신뢰하도록 등록하는 절차입니다.

  1. 크롬 플래그 페이지 접속:
    크롬 주소창에 아래 주소를 그대로 입력하고 접속합니다.
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Insecure origins treated as secure 활성화 및 주소 입력:
    목록에서 해당 플래그 항목의 우측 스위치를 Enabled로 변경한 뒤, 활성화되어 나타난 빈 텍스트 영역에 아래의 Ollama REST API 주소를 콤마(,) 구분으로 정확히 입력합니다.
    http://127.0.0.1:11434,http://localhost:11434
  3. 크롬 [다시 시작] (Relaunch) 실행:
    주소를 입력하고 나면 크롬 브라우저 우측 최하단에 생성되는 파란색 [다시 시작] (영문 크롬은 [Relaunch]) 버튼을 클릭합니다. 브라우저가 1초 만에 껐다 켜지며 보안 예외 설정이 즉시 반영됩니다.

Step 3. [최종 적용] 사이트 설정 및 기기에 있는 앱 권한 허용

크롬 브라우저가 재부팅되어 보안 설정이 적용된 후, 로컬 AI 통신 권한을 최종 부여하는 2가지 방법입니다.

  1. 연동하고자 하는 웹사이트 접속:
    로컬 AI(Ollama) 모듈과 통신해 작동시키려 하는 로컬 웹앱 또는 공개되어 있는 외부 웹 서비스(Open WebUI 등)에 접속합니다.
  2. 사이트 설정 메뉴 진입 (아래 2가지 경로 중 편한 방법 선택):
    • 방법 A (조절기 아이콘): 주소창 맨 좌측의 조절기 아이콘( 두 줄과 원 슬라이더 모양)을 클릭 ➔ [사이트 설정]을 클릭합니다.
    • 방법 B (세로 점 3개 메뉴): 크롬 우측 상단의 세로 점 3개(⋮) 클릭 ➔ [설정] ➔ [개인 정보 보호 및 보안] ➔ [사이트 설정]으로 이동합니다.
  3. [기기에 있는 앱] 권한 설정:
    [사이트 설정] 화면의 맨 아래로 스크롤하여 [추가 권한] ➔ [기기에 있는 앱] 메뉴를 클릭합니다.
    1) 기본 동작: "사이트에서 이 기기의 다른 앱 및 서비스에 대한 액세스 권한을 요청할 수 있음" 라디오 버튼을 선택합니다.
    2) 개별 사이트 등록: 아래 '이 기기의 다른 앱 및 서비스에 액세스하도록 허용됨' 항목 우측의 [추가] 버튼을 누른 뒤, 현재 사용 중인 웹사이트 주소(예: http://localhost:8000 등)를 입력하여 등록합니다.
  4. 화면 새로고침 (Cmd + R):
    설정을 마친 후 원래 웹사이트 탭으로 돌아와 키보드의 Cmd + R을 눌러 화면을 새로고침합니다.
  5. 연동 완료 및 AI 사용:
    이제 웹 화면에서 로컬 모델을 호출했을 때 차단 없이 정상적으로 AI 응답이 동작합니다. 🎉

자주 묻는 질문 (FAQ)

설정이 꼬이거나 여전히 연결되지 않을 경우 아래 가이드를 추가로 점검해보세요.

Insecure origins treated as secure 항목의 옵션을 Enabled로 바꾸지 않았거나, 입력 상자에 주소가 채워지지 않았을 경우 버튼이 뜨지 않습니다. Enabled로 먼저 세팅하고 주소 2개(http://127.0.0.1:11434,http://localhost:11434)를 기입하셨는지 다시 한번 확인해 주세요.
크롬 브라우저에서 아래 순서대로 진입하시면 됩니다.

1. 크롬 우측 상단 세로 점 3개(⋮) 클릭 ➔ [설정] 클릭
2. [개인 정보 보호 및 보안] ➔ [사이트 설정] 이동
3. 맨 밑으로 스크롤하여 [추가 권한] ➔ [기기에 있는 앱] 클릭
4. "사이트에서 이 기기의 다른 앱 및 서비스에 대한 액세스 권한을 요청할 수 있음"을 선택하거나, '이 기기의 다른 앱 및 서비스에 액세스하도록 허용됨'에 해당 사이트 주소를 추가합니다.
네, 그렇습니다. 이번 설정은 크롬 브라우저 엔진에 해당 로컬 포트 주소를 안전지대로 등록하는 것입니다. 로컬 개발 환경뿐만 아니라 인터넷상에 공개된 로컬 연동형 AI 챗봇 서비스에서도 동일하게 통신 차단이 해결됩니다.
한 줄씩 복사해서 실행하지 마시고, 가이드 내에 있는 [코드 복사] 버튼을 통해 전체 스크립트를 한 번에 복사한 뒤, 터미널 빈 화면에서 Cmd + V로 붙여넣고 엔터를 실행하시면 자동으로 설정 파일 생성과 시스템 등록이 완료됩니다.
