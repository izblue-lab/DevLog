Ollama Integration

로컬 AI 웹 브라우저 연동 가이드

웹사이트(웹앱)에서 내 컴퓨터의 Ollama 모델을 오류 없이 원클릭으로 쉽게 연결하고 사용하는 방법을 다룹니다.

매일 사용하는 3단계 실행 순서

복잡한 설정이 끝난 뒤, 평소에 로컬 AI를 사용할 때 진행하는 초간단 사용법입니다.

1
Ollama 앱 실행
맥 상단 메뉴바에 귀여운 라마 아이콘이 떠 있는지 확인합니다.
2
웹사이트 접속
로컬 AI를 연결해서 사용할 웹사이트 주소로 접속합니다.
3
보안 권한 허용
주소창 왼쪽 조절기(자물쇠) 버튼 클릭 ➔ [기기에 있는 앱]을 활성화합니다.
⚠️
중요 단계: [기기에 있는 앱] 스위치를 켠 뒤에는 브라우저 화면을 반드시 새로고침(F5 또는 Cmd+R)해야 변경된 보안 설정이 정상 반영됩니다!

[Mac 전용] 딱 1초 만에 끝내는 영구 자동화

컴퓨터를 부팅할 때마다 매번 터미널을 켜서 설정을 입력할 필요가 없도록, 맥의 시작 프로그램으로 환경 변수를 심어버리는 마법의 스크립트입니다.

  1. 맥에서 터미널(Terminal) 앱을 실행합니다. (Cmd + Space 누르고 '터미널' 검색)
  2. 아래 박스의 전체 명령어를 복사하여 터미널 창에 붙여넣고 엔터(Enter)를 칩니다.
ZSH / Shell script 
mkdir -p ~/Library/LaunchAgents && cat > ~/Library/LaunchAgents/com.ollama.origins.plist << 'EOF'




  Label
  com.ollama.origins
  ProgramArguments
  
    launchctl
    setenv
    OLLAMA_ORIGINS
    *
  
  RunAtLoad
  
  ServiceIPC
  


EOF
launchctl load ~/Library/LaunchAgents/com.ollama.origins.plist
launchctl setenv OLLAMA_ORIGINS "*"
echo "🎉 영구 자동화 설정 완료! Ollama 앱을 재시작해주세요!"
💡
마지막 꿀팁: 맥이 켜질 때 Ollama가 자동으로 실행되도록 설정하는 방법
  • 맥 화면 좌측 상단의 애플 메뉴() ➔ [시스템 설정]을 클릭합니다.
  • 왼쪽 사이드바에서 [일반]을 누른 뒤, [로그인 항목] 메뉴로 이동합니다.
  • '로그인할 때 열기' 목록 아래의 [＋] 버튼을 클릭합니다.
  • 응용 프로그램(Applications) 폴더에서 Ollama 앱을 선택하여 추가해 줍니다.

웹앱에서 강제로 모델 바꾸기 (복사/엘리어싱)

웹사이트의 코드 안에서 호출하는 모델명이 고정되어 수정할 수 없을 때, Ollama 내부에서 이름표만 덮어씌워 원하는 최신 고성능 모델로 구동시키는 비법입니다.

예시: qwen3.5-flash 호출 요청을 고성능 gemma4:e4b 모델로 대체하여 작동시키고 싶을 때

Ollama CLI 
# 1. 웹사이트가 요구하는 기존 가짜 모델명이 로컬에 이미 설치되어 있다면 삭제
ollama rm qwen3.5-flash:latest

# 2. 내가 실제로 실행시키고 싶은 진짜 고성능 모델을 가짜 이름표로 복사 매핑
ollama cp gemma4:e4b qwen3.5-flash:latest

*(참고: 두 이름의 내부 ID가 동일하게 묶이므로 용량을 이중으로 차지하지 않고 바로 링크됩니다.)*

자주 묻는 질문 (FAQ)

연동에 어려움을 겪고 계신다면 아래 해결법을 차근차근 확인해보세요.

웹 브라우저의 기본 설정에서 직접 허용할 수 있습니다.

1. 크롬 우측 상단 점 3개(⋮) 클릭 ➔ [설정] 클릭
2. [개인정보 및 보안] ➔ [사이트 설정] 이동
3. 맨 밑으로 스크롤하여 [추가 권한] ➔ [기기에 있는 앱] 메뉴 클릭
4. 해당 웹사이트가 '허용' 목록에 추가되어 있는지 확인하고 등록해 줍니다.
터미널을 열고 아래 명령어를 입력한 뒤 엔터를 칩니다.

launchctl getenv OLLAMA_ORIGINS

실행 결과로 *가 예쁘게 한 줄 출력된다면 백그라운드 환경 변수 등록이 완벽하게 성공한 상태입니다!
환경 변수(CORS 허용 옵션)는 시스템에 등록되었더라도, 이미 백그라운드에서 돌고 있는 Ollama 프로그램이 켜질 때의 이전 환경 변수를 물고 있기 때문입니다. 앱을 완전히 종료했다가 다시 실행해 주어야 새로운 CORS 설정을 시스템에서 가져오게 됩니다.
